# Electron 테스트 실행

쇼츠팩토리는 웹 UI를 그대로 사용하면서 Electron 데스크톱 창으로 실행할 수 있습니다.

## 실행

```bash
npm run electron
```

또는 같은 명령의 별칭:

```bash
npm run desktop
```

첫 실행에서는 `npx`가 Electron을 내려받을 수 있으므로 인터넷 연결이 필요할 수 있습니다.

## 테스트 순서

1. 앱이 열리면 `사용법` 탭을 먼저 봅니다.
2. `기획`에서 상품명, 제휴 링크, 불편 포인트, 장점을 입력합니다.
3. `AI엔진`에서 테스트 생성, GPT 이미지, Gemini 이미지, 리더스 나노바나나프로 중 하나를 고릅니다.
4. `AI 스토리`에서 대본을 입력하고 `현재 대본으로 이미지 생성`을 실행합니다.
5. `영상편집`에서 `영상 선택`을 눌러 클립을 가져오거나, 생성된 이미지 순서를 확인합니다.
6. `무음구간 편집`에서 클립을 고르고 `무음구간 분석`을 실행한 뒤 `말 있는 구간만 타임라인에 적용`을 눌러 컷을 반영합니다.
7. 이미지 기반 영상은 `이미지 순서로 영상 클립 만들기`를 실행합니다.
8. `플랫폼`에서 제목, 캡션, 고정 댓글, 해시태그를 확인합니다.
9. `저작권`에서 참고 전용과 편집 사용 소스를 구분합니다.
10. `출력`에서 `로컬 저장`, `검증 실행`, `렌더 실행`, `패키지 실행` 순서로 테스트합니다.

Electron에서는 선택한 영상/이미지를 프로젝트 폴더로 복사합니다. 브라우저 화면에서는 업로드 방식으로 같은 흐름을 테스트합니다.

AI 키는 실행 순간에만 사용하고 프로젝트 파일에는 저장하지 않습니다. 키를 앱에 입력하지 않을 때는 `OPENAI_API_KEY`, `GEMINI_API_KEY`, `LEADERS_NANO_BANANA_API_KEY`, `LEADERS_NANO_BANANA_ENDPOINT`, `TYPECAST_API_KEY`(타입캐스트 AI 성우), `HIGGSFIELD_API_KEY`/`HIGGSFIELD_SECRET`(힉스필드 영상화) 환경변수를 사용할 수 있습니다.

렌더 실행은 실제 클립 파일과 FFmpeg/ffprobe가 준비되어야 성공합니다.

## 자동자막

`영상편집` 탭의 `자동자막` 섹션에서 클립을 고른 뒤 `자동자막 환경 확인`을 누르면 FFmpeg, FFprobe, 로컬 Whisper, Python, pip 상태를 확인합니다.

- 바로 UI 흐름을 테스트하려면 엔진을 `테스트 자막`으로 두고 `자동자막 생성`을 누릅니다.
- 실제 음성 인식을 사용하려면 FFmpeg와 로컬 Whisper가 필요합니다. Windows 기준 예시는 `winget install Gyan.FFmpeg`, `python -m pip install -U openai-whisper`입니다.
- PATH에 잡히지 않으면 `FFMPEG_PATH`, `FFPROBE_PATH`, `WHISPER_BIN` 환경변수로 실행 파일 경로를 지정한 뒤 앱을 다시 실행합니다.
- Whisper 모델은 기본적으로 앱 실행 폴더의 `.cache/whisper`에 저장합니다. 다른 위치를 쓰려면 `SF_WHISPER_MODEL_DIR`을 지정합니다.
- 생성된 SRT는 프로젝트 폴더의 `captions/*.auto.srt`로 저장됩니다. 이후 `렌더 실행`을 누르면 해당 SRT가 자동으로 최종 영상 자막 오버레이에 반영됩니다.

## 타임라인 V1

`영상편집` 탭에서 영상을 선택하면 오른쪽 프리뷰와 `타임라인 V1` 작업대가 같은 클립을 바라봅니다.

1. `영상 선택`으로 클립을 가져오면 첫 번째 새 클립이 자동 선택됩니다.
2. 상단 미리보기에서 현재 선택된 클립을 재생해 확인합니다.
3. `타임라인 V1`의 트랙 조각을 누르면 해당 장면으로 이동합니다.
4. 플레이헤드 슬라이더를 움직여 분할할 위치를 잡고 `현재 위치에서 분할`을 누릅니다.
5. `시작`, `종료` 값을 직접 고치거나 `앞 0.1초 컷`, `뒤 0.1초 컷`으로 빠르게 다듬습니다.
6. 필요 없는 장면은 `선택 장면 삭제`로 제거합니다.

## 자막 편집 저장

`자동자막 생성` 후에는 자막 줄마다 시작/종료 시간과 문구를 직접 수정할 수 있습니다.

1. 자막 줄의 `시작`, `종료`, 문구를 고칩니다.
2. 너무 짧게 쪼개진 줄은 `다음 줄과 합치기` 버튼으로 병합합니다.
3. 필요 없는 줄은 삭제합니다.
4. `자막 수정 저장`을 누르면 같은 SRT 파일에 수정본이 저장됩니다.
5. 이후 `렌더 실행`을 누르면 수정된 SRT가 최종 영상에 반영됩니다.
