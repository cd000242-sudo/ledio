# 블로그 → AI 영상 파이프라인 플랜

> 2026-07-07 작성. 목표: 키워드 리서치 → 블로그 글 작성 → 그 글로 AI 영상 제작(수익화).
> 현재 앱은 "주제 → 썰 대본 → 쇼츠" 구조라, "글 → 영상" 변환 계층이 없다. 이 문서가 그 설계.

## 심층 분석

### 1. 왜 이 조합이 강한가
- 같은 리서치 1번으로 **블로그(애드센스/제휴) + 유튜브(조회수익) 이중 수익**.
- 블로그 키워드 = 이미 검색 수요가 검증된 주제 → 영상도 검색 유입(유튜브 SEO)을 탄다.
- 블로그 글이 영상 대본의 "사실 원천"이 되므로 정보 오류가 줄고 제작이 빨라진다.

### 2. 콘텐츠 유형이 다르다 — 공포썰과 결정적 차이
| | 공포썰(현재 주력) | 블로그 기반 정보 영상 |
|---|---|---|
| 구조 | 기승전결 + 반전 | 문제 제기 → 핵심 답 → 근거/방법 → 정리 |
| 톤 | 이야기꾼 | 차분한나레이션 or 하이텐션(주제에 따라) |
| 이미지 | 드라마 스틸컷 + 인물 고정 | **인포그래픽/자료화면 스타일** — 인물 불필요, 스타일 일관성만 |
| 포맷 | 숏폼 위주 | **롱폼 16:9 본편 + 숏폼 하이라이트 2~3개** |
| 후킹 | 공포/궁금증 | "이거 모르면 손해" 류 실익 후킹 |

### 3. 추천 영상 공식 (1 글 → 1+3 패키지)
1. **롱폼 16:9 (5~10분)** — 글 전체를 영상 대본으로 압축. 검색 유입 + 시청시간 수익.
2. **숏폼 9:16 × 2~3개** — 글의 핵심 꿀팁을 하나씩 떼어 60초 영상. 채널 유입 트래픽.
3. 영상 설명란에 블로그 링크 → 상호 트래픽 순환.

### 4. 지금 앱으로 어디까지 되나
- ✅ 롱폼 16:9 / 숏폼 9:16 파이프라인, 낭독, 자막, BGM, 이미지 일관성
- ✅ 에이전트(WebSearch) 리서치 인프라 (RESEARCH_GENRES에서 이미 사용)
- ❌ 키워드 리서치 / 블로그 글 작성 기능 없음
- ❌ "긴 글 → 영상 대본" 변환 없음 (대본 입력은 주제 한 줄 기반)
- ❌ 정보형 이미지 스타일 프리셋 없음 (지금은 드라마 실사풍 고정)

## 구현 플랜 (우선순위 순)

### 1단계 — "글 → 영상 대본" 변환 (반나절) ★먼저
AI 숏폼 만들기에 **"긴 글 붙여넣기 → 영상 대본으로 변환"** 버튼.
- 입력: 블로그 글 전문(외부에서 쓴 글도 OK) + 목표 길이(숏폼 60초/롱폼 N분)
- 프롬프트: 정보 구조(후킹→핵심 답 먼저→근거→실전 방법→정리+CTA), 라디오 사연체 대신 정보 전달체, 기존 신속정확 엔진 재사용
- 이것만 있어도 "블로그 글 → 영상"이 수동으로 완성된다

### 2단계 — 정보형 이미지 프리셋 (반나절)
이미지 스타일 선택 추가: 실사 드라마풍(기본) / **깔끔한 인포그래픽 일러스트** / 다큐 자료화면풍.
- 정보형은 인물 고정·세트 시트 대신 "컬러 팔레트+그래픽 스타일 일관성" 프롬프트로 전환
- 숫자·비교는 화면에 크게 보이는 구도 지시

### 3단계 — 블로그 스튜디오 탭 (1~2일)
새 서브탭 "블로그 → 영상":
1. 키워드 입력 → 에이전트가 WebSearch로 리서치(검색 의도, 경쟁 글, 소제목 구조 제안)
2. SEO 블로그 글 생성 (제목/소제목/본문/메타설명) → 복사·저장
3. 같은 화면에서 [롱폼 대본 만들기] [숏폼 하이라이트 3개 뽑기] 버튼 → 1단계 변환기 호출
4. 글·대본 모두 보관함에 세트로 저장

### 4단계 — 원버튼 패키지 (2단계까지 안정화 후)
키워드 하나 → 블로그 글 + 롱폼 영상 + 숏폼 3개 자동 생산. 각 단계 산출물 확인 후 진행하는 반자동이 현실적.

## 운영 팁 (기능과 무관하게 지금부터)
- 키워드는 "질문형 + 숫자형"이 영상 전환이 잘 된다 (예: "전세보증금 돌려받는 법 5가지").
- 블로그 글은 소제목(H2) 단위로 쓰면 1단계 변환기가 장면을 깔끔하게 나눈다.
- 롱폼은 차분한나레이션 톤 + 정보형 포맷, 숏폼 하이라이트는 하이텐션 톤이 CTR가 좋다.

## 착수 신호
"1단계 해줘" / "글 변환 버튼 만들어줘" 등 지시가 오면 해당 단계부터 구현.
