# PART 0. 지식 격차 — 확인된 사실과 남은 미지수

> "저쪽이 어떻게 구현했는지 모른다"는 지적이 정확하다. **추측 금지 영역**을 먼저 확정한다.

## 0.1 오늘 웹 조사로 확정된 사실 (계획 수정 근거)

### ① 캡컷 draft 포맷 — ⚠ 계획 대폭 수정 필요
- **캡컷/젠잉 6버전 이상은 `draft_content.json`을 암호화한다.** 평문 JSON이 아니다.
- 대표 오픈소스 `pyJianYingDraft`는 **5.9 이하만 지원**한다고 명시.
- 관련 도구: `capcut-cli`(draft_content.json 직접 읽기), `VectCutAPI`.
- 필요 파일은 2개: `draft_content.json`(타임라인) + `draft_meta_info.json`(소재 라이브러리).
- **결론**: "캡컷 내보내기"를 무조건 되는 기능으로 약속하면 안 된다.
  → **T0.1 프로브 필수**: 사용자 PC의 캡컷 버전 확인 → 암호화 여부 실측 → 되면 구현, 안 되면 대안(아래 0.3).

### ② 자막 제거 — 직접 구현 금지, 검증된 것을 어댑터로
- 사실상 표준: **`video-subtitle-remover`(YaoFANGUK)** — STTN / LaMa / ProPainter 3종 인페인팅 + GPU.
- **STTN이 자막 제거에 최적**인 이유: 자막은 시간적으로 희소해서, **자막이 바뀌거나 사라지는 프레임에 배경이 드러난다** → 인접 프레임에서 실제 배경을 복원(합성이 아님).
- LaMa = 단일 프레임 신경망 채움 / ProPainter = 전파+트랜스포머 하이브리드 / DiffuEraser = ProPainter 결과 + 확산 초기화.
- **결론**: 우리는 모델을 만들지 않는다. **어댑터로 붙이고, 없으면 delogo 폴백.** (드롭샷/힉스필드와 동일 패턴)

### ③ yt-dlp 플랫폼별 신뢰도 — 등급을 UI에 노출해야 함
| 플랫폼 | 상태 | 대응 |
|---|---|---|
| 유튜브 | ✅ 안정 | 기본 경로 |
| 틱톡 | ✅ 공개 영상은 쿠키 없이 동작 | 기본 경로 |
| 더우인 | ⚠ **쿠키 필수 + 자주 깨짐** (이슈 다수: "fresh cookies" 오류 반복) | 쿠키 가져오기 안내 + 실패 시 수동 폴백 |
| 샤오홍슈 | ❓ 공식 지원 불명확 | **T0.2 프로브로 실측 후 결정** |
- yt-dlp는 매일 업데이트되므로 **버전 고정 금지, 자동 업데이트 안내** 필요.

## 0.2 착수 전 프로브 태스크 (T1.1보다 먼저 — 반나절)

**T0.1 캡컷 포맷 실측** (1시간)
- 캡컷에서 더미 프로젝트 1개 생성 → draft 폴더 열기 → `draft_content.json` 앞부분 확인
- 판정: 평문 JSON이면 → Phase 4-C 그대로 진행 / 암호화면 → 0.3 대안으로 교체
- 산출: `docs/capcut-probe-result.md` (버전, 경로, 암호화 여부, 필드 샘플)

**T0.2 플랫폼 다운로드 실측** (1시간)
- yt-dlp 설치 후 각 플랫폼 링크 3개씩 실제 다운로드 시도 (유튜브/틱톡/샤오홍슈/더우인)
- 산출: `docs/platform-probe-result.md` — 성공률, 필요 쿠키, 에러 문구
- 이 결과가 **Phase 1 UI의 플랫폼 배지(안정/주의/수동)** 를 결정한다

**T0.3 인페인팅 환경 실측** (1시간)
- `video-subtitle-remover` 계열을 로컬 GPU(RTX 4060 8GB)에서 STTN 모드로 시험
- 판정: VRAM 초과하면 → 해상도 낮춰 처리 후 업스케일, 그래도 안 되면 delogo 고정
- 산출: `docs/inpaint-probe-result.md` — 모델별 VRAM/속도/품질

**T0.4 샤오홍슈/더우인 검색 URL 실측** (30분)
- 브라우저에서 검색 1회 → 실제 URL 패턴 복사 (검색어 파라미터 이름이 바뀌었을 수 있음)
- 산출: `src/sourcing/searchUrls.ts`의 상수로 직접 반영

> **원칙: 프로브 없이 구현 시작 금지.** 위 4개는 총 3.5시간이고, 잘못된 가정으로 4일 날리는 것을 막는다.

## 0.3 캡컷이 암호화된 경우의 대안 (우선순위 순)
1. **프로젝트 폴더 내보내기**: `final.mp4` + `narration.wav` + `subtitle.srt` + `bgm.mp3` + `sources/` 를 한 폴더에. 캡컷에서 드래그 임포트 (2분 작업, 100% 확실)
2. **프리미어/다빈치 XML(FCPXML)**: 공개 규격이라 안정적. 전문 편집 사용자에게 오히려 상급
3. **캡컷 5.9 호환 draft**: 구버전 사용자만 대상으로 제공(위험 고지)
4. **자체 편집기 강화**: 이미 타임라인 편집기가 있으므로, 캡컷 없이 끝내는 경로를 밀어붙임 ← **장기적으로 이게 정답**

## 1.1 설계 철학 (저쪽과의 차이)

## 1.3 단계별 UI 명세

### ① 제품 찾기
- 입력: 큰 URL 붙여넣기 필드 1개 + [분석] (엔터로도 실행)
- 결과 카드: 썸네일 · 제품명(수정 가능) · 특징 칩 · 카테고리
- 검색 그리드: 6사이트 × 언어 배지, 각 버튼에 **신뢰도 배지**(안정/주의/수동) — T0.2 결과 반영
- 프레임 스트립: 추출 프레임 5장, 각각 [역검색] 버튼
- **실패 UX**: 다운로드 실패 시 → 에러 분류별 한국어 안내 + [파일 직접 넣기] 버튼 즉시 노출

### ② 소스 수집
- 3열 카드: **URL 붙여넣기** / **파일 드롭** / **AI로 생성**(우리만의 것 — 강조 배치)
- 소스 목록: 썸네일·길이·해상도·자막감지 배지(있음/없음)·[미리보기]·[제거]
- **커버리지 게이지**: "대본 20초 중 소스로 12초 커버 · 8초 부족 → AI로 채우기" ← 킬러 UI
- 정렬: 드래그로 순서 변경

### ③ 대본
- 좌: 구간 리스트(썸네일+타임코드+길이) / 우: 대본 편집
- 각 줄: 글자수/초과 경고 배지, [이 구간만 재생], [이 문장만 재생성]
- 상단: 스타일 프로필 드롭다운 + [이 스타일로 다시 생성]
- 하단: 예상 낭독 길이 실시간 계산(초당 4.5자)

### ④ 음성
- 목소리 카드 그리드: 이름·태그·[미리듣기]·⭐즐겨찾기 (타입캐스트/일레븐랩스/내 목소리 클로닝 그룹)
- 설정: 속도 슬라이더(1.0~1.6, 기본 1.3)·감정·무음 삭제 토글
- [전체 생성] 후 문장별 파형 + 개별 재생성

### ⑤ 자막
- 실시간 프리뷰 캔버스(대표 프레임 위 자막 오버레이) + **드래그로 위치**
- 우측 패널: 폰트·크기·색·테두리·배경·효과·정렬(XY중앙 버튼)
- 프리셋 저장/불러오기 (채널 아이덴티티 고정용)

### ⑥ 완성
- 최종 미리보기 + [MP4] [SRT] [프로젝트 폴더] [캡컷] (T0.1 결과에 따라 캡컷 버튼 활성/비활성 + 사유 툴팁)
- SEO 패널: 제목 5안(라디오 선택) · 플랫폼별 탭 · 각 [복사] 버튼
- 링크 페이지 바로가기

## 1.4 인터랙션 원칙 (전 화면 공통)
1. **클릭 즉시 반응**: 서버 응답 전에 낙관적 상태 표시(진행바 4%), 실패 시 롤백
2. **모든 파괴적 동작에 확인**: 삭제·덮어쓰기·전체 재생성
3. **되돌리기**: 대본/자막 편집은 Ctrl+Z (기존 편집기 undo 패턴 재사용)
4. **키보드**: Enter=실행, Esc=취소, ←/→=구간 이동, Space=재생/정지
5. **빈 상태 안내**: 각 단계 빈 화면에 "무엇을 하면 되는지" 한 줄 + 예시
6. **한국어 오류만 노출**: 기술 메시지는 [자세히] 접기 안에

## 1.5 디자인 시스템 (이미 적용된 다크 프리미엄 유지)

# PART 2. 아키텍처 — 안 꼬이고 안 터지는 구조

## 2.1 단방향 데이터 흐름 (절대 규칙)

```
UI(표시만) → API(얇은 라우팅) → 큐 → CLI(실행) → 파일(진실의 원천)
                                              ↓
UI ← API(파일 읽기) ←──────────────────────────┘
```
- **UI는 상태를 소유하지 않는다.** 화면은 파일/API의 투영일 뿐.
- 새로고침해도 상태가 복원된다(= 상태는 항상 디스크에 있다).

## 2.2 프로젝트 매니페스트 — 단일 진실

`projects/<id>/project.json` 하나가 프로젝트 전체를 기술한다.

```jsonc
{
  "version": 1,                    // 마이그레이션용 (필수)
  "id": "prj_...", "title": "...",
  "ratio": "9:16",
  "steps": {                       // 각 단계 상태 — UI 스텝 레일이 이걸 그대로 그림
    "discovery": {"state":"done","at":"...","error":null},
    "sources":   {"state":"running"},
    "script":    {"state":"idle"}, ...
  },
  "product": {...},                // ① 산출
  "sources": [{id,path,duration,hasSubtitle,origin}], // ②
  "script":  {"styleId":"...","lines":[{index,start,end,text}]}, // ③
  "voice":   {"provider":"typecast","voiceId":"...","speed":1.3,"files":[...]}, // ④
  "captions":{"style":{...}},      // ⑤
  "output":  {"video":"...","srt":"...","seo":{...}} // ⑥
}
```

**규칙**
- 각 단계는 **자기 섹션만** 쓴다(교차 수정 금지 → 꼬임 원천 차단).
- 쓰기는 항상 **원자적**: 임시 파일 쓰고 rename.
- 스키마는 zod로 정의(`src/project/manifest.ts`), 읽을 때마다 검증 + 버전 마이그레이션.

## 2.3 어댑터 패턴 — 외부 의존은 전부 갈아끼울 수 있게

```ts
interface SourceDownloader { name; isAvailable(): Promise<boolean>; download(url, opts): Promise<Result> }
interface SubtitleRemover  { name; isAvailable(): Promise<boolean>; remove(video, band): Promise<Result> }
interface ProjectExporter  { name; isAvailable(): Promise<boolean>; export(manifest, out): Promise<Result> }
```
- 구현체: `YtDlpDownloader` / `SttnRemover`·`DelogoRemover` / `CapcutExporter`·`FolderExporter`·`FcpxmlExporter`
- **선택은 런타임에**: `pickFirstAvailable([A, B, C])` — 없으면 자동으로 다음 것
- **하드 의존 금지**: 어떤 어댑터가 없어도 앱 전체가 동작해야 한다(이미 드롭샷/힉스필드에서 검증된 원칙)

## 2.4 에러 체계 — "절대 안 터지게"

```ts
type AppError = {
  code: string            // 'DOWNLOAD_LOGIN_REQUIRED'
  userMessage: string     // 한국어 + 다음 행동 ("로그인이 필요한 영상입니다. 파일로 직접 넣어주세요.")
  technical?: string      // 접힘 영역에만
  recoverable: boolean
  fallback?: {label, action}  // UI가 버튼으로 렌더 ([파일 직접 넣기])
}
```

**5계층 방어**
1. **경계 검증** — 모든 API 입출력·LLM 응답·외부 프로세스 출력은 zod 스키마 통과 필수
2. **관대한 파서** — LLM JSON은 코드펜스/설명 섞여도 추출(기존 패턴), 실패 시 1회 재시도
3. **타임아웃 + 트리 종료** — 모든 장기 작업(이미 구현된 `withDeadline`·`killChildTree` 확장)
4. **폴백 체인** — 인페인팅 실패 → delogo → 블러 → 그냥 진행
5. **크래시 격리** — 서버 라우팅에 최상위 try/catch(있음), CLI는 실패해도 exitCode만 반환

**금지**: `throw`로 UI까지 올려보내기 / 영문 에러 그대로 노출 / 조용한 실패(무반응)

## 2.5 모듈 경계 (꼬임 방지)

```
src/project/     매니페스트 스키마·읽기·쓰기·마이그레이션   ← 모두가 의존, 아무에게도 의존 안 함
src/sourcing/    yt-dlp·프레임·검색URL·장면감지 (순수+CLI)
src/style/       스타일 프로필 스키마·적용
src/export/      캡컷·FCPXML·폴더 내보내기
src/adapters/    인터페이스 정의 + 구현체 등록
scripts/server/  프롬프트(순수) + 핸들러(얇게)
app/             화면 (서버 API만)
```
- **순환 import 금지** (eslint `import/no-cycle` 규칙 추가)
- 의존 방향: `app → server → cli → src/도메인` (역방향 금지)

## 2.6 멱등성 & 재개
- 모든 단계는 **다시 실행해도 안전**해야 한다(같은 입력 → 같은 결과, 부분 산출물 덮어쓰기 안전).
- 산출물이 이미 있으면 스킵(기존 파이프라인 재개 로직 확장).
- 취소 시 반쯤 만든 파일은 `.tmp` 확장자로 두고 정리.

# PART 3. 성능 — 빠르고 정확하게

## 3.1 시간 예산 (목표치, 초과 시 최적화 대상)

| 단계 | 목표 | 병목 | 대책 |
|---|---|---|---|
| 제품 인식 | 15초 | 비전 API | 프레임 3장, 결과 캐시(URL 해시) |
| 영상 다운로드 | 30초/개 | 네트워크 | **병렬 3개**(네트워크는 병렬 안전) |
| 장면 분석 | 10초 | ffmpeg | 저해상도 프록시로 분석 |
| 대본 생성 | 20초 | LLM | 빠른 모델(haiku급) 우선 |
| 음성 생성 | 20초 | TTS API/GPU | 문장 캐시(구현됨) + 클라우드는 병렬 |
| 자막 제거 | 60초/개 | GPU | 480p 처리 후 업스케일 |
| 최종 렌더 | 40초 | ffmpeg | NVENC 하드웨어 인코딩 |
| **총합** | **3~5분** | | |

## 3.2 병렬화 규칙 (충돌 방지)
| 자원 | 동시 실행 | 근거 |
|---|---|---|
| GPU(TTS·인페인팅) | ❌ **직렬** | 이미 2시간 사고로 검증됨 |
| 드롭샷 브라우저 프로필 | ❌ **직렬** | 프로필 단일 점유 |
| 네트워크(다운로드·API) | ✅ 최대 3~4 | |
| ffmpeg(컷·인코딩) | ✅ 최대 2 | CPU 코어 여유 |
- 큐에 **자원 태그**를 붙여 스케줄링: `{resource: 'gpu'|'browser'|'net'|'cpu'}`

## 3.3 캐시 계층
| 대상 | 키 | 위치 |
|---|---|---|
| 제품 인식 | URL 해시 | `tmp/cache/identity/` |
| 프레임 | 파일 해시+타임스탬프 | `tmp/cache/frames/` |
| 대본 | 입력 해시(제품+스타일+길이) | `tmp/cache/script/` |
| TTS 덩어리 | 목소리서명+텍스트 | 구현됨 |
| 다운로드 영상 | URL 해시 | `tmp/cache/source/` |
- 전부 **상한 + LRU 정리**(구현된 `pruneChunkCache` 패턴 재사용)

## 3.4 정확도 장치
- LLM 출력 → 스키마 검증 → 실패 시 1회 재시도 → 그래도 실패하면 **사람이 채우는 UI**로 폴백(빈 화면 금지)
- 대본↔구간 수 불일치 자동 보정(T2.7)
- 글자수/시간 적합성 사전 경고(T2.8) — 렌더 후에 알면 늦다

# PART 4. 실행 명세서 수정 사항

`shopping-factory-execution-spec.md`에 아래를 반영한다.

1. **T0.1~T0.4 프로브를 T1.1보다 먼저** 실행(반나절). 결과 문서 3개 생성.
2. **T4.13~T4.16(캡컷)** → T0.1 결과에 따라 분기. 암호화면 **폴더 내보내기 + FCPXML**로 대체하고 캡컷은 "5.9 이하 실험 기능"으로 격하.
3. **T4.4(인페인팅)** → 자체 구현이 아니라 **`video-subtitle-remover` 계열 어댑터 연결**로 명시. STTN 우선.
4. **T1.2** → 플랫폼별 신뢰도 등급 상수 추가(`PLATFORM_RELIABILITY`), UI 배지에 노출.
5. **신규 T0.5** — `src/project/manifest.ts`(매니페스트 스키마)를 **가장 먼저** 만든다. 모든 단계가 여기에 의존하므로 이게 없으면 나중에 전면 리팩터가 발생한다.
6. **신규 T0.6** — `src/adapters/index.ts`(어댑터 인터페이스 + `pickFirstAvailable`). 외부 의존 추가 전에 골격부터.
7. eslint에 `import/no-cycle` 규칙 추가(T0.7, 15분).

T0.5(매니페스트) → T0.6(어댑터 골격) → T0.7(순환금지 린트)
