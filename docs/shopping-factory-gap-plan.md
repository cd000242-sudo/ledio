> 2026-07-07 작성. 대상: 유튜브 판매 영상의 "쇼핑 팩토리" (18분 데모 전 기능 분석).

## 2. 전략 — 똑같이 만들면 진다

**저쪽의 구조적 약점 (본인들도 인정한 것):**
- 짜깁기는 **원본 영상이 있어야만** 만들어진다 → 신제품·마이너 제품은 못 만든다.
- 같은 소스를 여러 구독자가 쓴다 → 중복. (저쪽이 "믹스로 중복 회피"를 기능으로 파는 것 자체가 문제의 자백)
- 남의 영상 재사용 → 저작권 클레임·계정 정지 리스크가 구독자에게 전가된다.

**우리 축: 짜깁기 + AI 생성 하이브리드.**
- 소스가 있으면 짜깁기(저쪽과 동급), 없으면 **상품 이미지 → AI 이미지 → i2v로 아예 새로 생성**.
- 부족한 장면만 AI로 메우는 혼합 모드 → 중복 0, 저작권 리스크 최소, 소재 고갈 없음.
- 여기에 **내 목소리 클로닝**(저쪽은 공용 TTS라 채널끼리 목소리가 겹침)까지 더하면 차별화는 명확하다.

**저쪽의 진짜 해자는 기술이 아니라 큐레이션(추천픽 피드)+커뮤니티(단톡방)+마케팅이다.** 기술은 2~3주면 따라잡는다.

## 3. 울트라플랜 (Phase 순서 = 착수 우선순위)

### Phase 1 — 입구 만들기 · 2~3일 ★없으면 아무것도 시작 못 함
링크 하나 붙여넣기 → 다운로드 → 제품 인식 → 검색어 팩.
- yt-dlp 통합(감지·설치 안내·실패 시 파일 폴백)
- 프레임 추출(이미 있음) + 비전(이미 있음) → 제품명·특징 자동 인식
- 6대 사이트 검색어 자동 생성(한/중/영) + 클릭하면 해당 사이트 검색 열기

### Phase 2 — 영상 보고 대본 (비전 조립) · 1~2일
편집된 영상의 장면별 프레임 → 비전 → **장면 타임코드에 맞는 대본** 생성.
- 부품이 전부 있어서 배선만 하면 됨. 저쪽 데모의 핵심 "정확한 구간에 대본" 대응.

### Phase 3 — 스타일 학습 & 레퍼런스 모음집 · 2일
잘 나가는 영상 링크 → STT + 비전 → **톤·말투·문장구조·자막패턴 학습 → 스타일 프로필 저장 → 그 스타일로 재생성**.
- 충청도 사투리 같은 개인 스타일도 여기에 저장(별도 하드코딩 불필요).

### Phase 4 — 마감 품질 · 3~4일
- **자막 제거**: ffmpeg delogo로 1차 → 부족하면 로컬 GPU 인페인팅(LaMa/STTN). 저쪽도 "100% 완벽하진 않다"고 인정.
- **자막 스타일 에디터**: 폰트·색·두께·위치 드래그·효과·상하 템플릿.
- **캡컷 내보내기**: draft JSON 생성(리버스 엔지니어링). 편집 여지를 남기는 실사용 필수 기능.

### Phase 5 — 우리만의 킬러: 하이브리드 생성 · 1~2일 (부품 대부분 존재)
- 소스 부족분 자동 감지 → 상품 이미지 → AI 이미지 → i2v로 **없는 장면을 만들어 채움**
- "완전 오리지널 모드"(소스 0개로 제작) 스위치
- 내 목소리 클로닝 프리셋

### Phase 6 — 수익화 도구 · 2~3일
- SEO 패키지: 제목 5안 + 플랫폼별 설명·태그 + 댓글 유도 문구
- 링크 페이지 빌더(인포크링크 대체): 정적 페이지 생성 + GitHub Pages 무료 호스팅 + 쿠팡 링크 블록 관리

**총 2~3주. Phase 1·2만 끝나도 저쪽 데모의 70%가 커버된다.**

## 4. 리스크
1. **유사 영상 자동 탐색**은 플랫폼 봇 차단이 강해 100% 자동을 약속하면 안 된다(저쪽도 실제론 반자동일 가능성이 높다). 우리는 "검색어 + 원클릭 열기 → 사용자가 담기"로 시작하고 자동 수집은 후순위.
2. **저작권** — 짜깁기 기능을 파는 순간 구매자 리스크를 우리가 떠안는 구조가 된다. 하이브리드/오리지널 모드를 기본값으로 두는 것이 제품 방어에도 유리.
3. **판매용이면 별도 비용** — 라이선스·업데이트·가이드·CS. 기술 완성 ≠ 제품 완성.
